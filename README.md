# Webcam Workshop

A collection of interactive games and demos that use your webcam, mouse, or
keyboard. Camera images stay on your computer and are not uploaded or recorded.

## Run the project

1. Download and install the **LTS** version of [Node.js](https://nodejs.org/).
   Node.js includes `npm`, which installs and runs the project.
2. Open a terminal in this project folder.
3. Run:

```sh
npm ci
npm run dev
```

4. Open the local web address shown in the terminal, usually
   `http://localhost:5173`.

Allow camera access when asked, or choose **Pointer / keys** to play without a
camera. Press `Ctrl+C` in the terminal when you want to stop the project.

Want to create an activity? Read [Add one demo](docs/adding-a-demo.md).
